# Personal Resume Website
A simple and clean resume website built using HTML to display  my skills, projects, education and contact information.

# 📄 About the Project
This project is a personal resume webpage designed to present my profile as a Computer Science student and frontend developer.
It includes sections such as About Me, Skills, Experience, Projects, Education, and Contact Details.

 # 🚀 Features
- Clean and simple layout  
- Easy to read structure  
- Student-friendly personal website format  
- Project and education details included
